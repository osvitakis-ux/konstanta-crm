# CRM «Константа»

Вебзастосунок (PWA) на чистому JavaScript без збирача, дані — у Supabase.

## Структура

- `index.html` — розмітка; підключає `styles.css` і файли з `js/` по черзі.
- `styles.css` — усі основні стилі.
- `js/01-…js` … `js/35-…js` — код застосунку, розбитий на модулі за темами.
- `sw.js` — сервіс-воркер (network-first для коду, тож нова версія підтягується сама).

## Правила для модулів

- Це звичайні скрипти, не ES-модулі: усі функції й `var` верхнього рівня глобальні й видимі з будь-якого файлу.
- **Порядок файлів важливий.** Код, що виконується одразу при завантаженні (а не всередині функції чи обробника подій), може викликати лише функції з того самого або попередніх файлів.
- Рядки на кшталт `window.foo = foo;` для функцій із пізніших файлів додавай у `js/35-window-exports.js`, а не вище за оголошення.
- Нову функцію клади у файл відповідної теми. Новий файл — додай `<script>` в `index.html` у потрібне місце з тим самим `?v=`.
- Не використовуй `let`/`const` на верхньому рівні з однаковими іменами в різних файлах — це помилка повторного оголошення.

## Перевірка й реліз

- Хук `.claude/hooks/check-syntax.js` сам перевіряє синтаксис після змін.
- `/release [опис]` — оновлює версії кешу та `?v=` в усіх підключеннях, комітить і пушить.
